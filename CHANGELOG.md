# SearXNG Search Changelog

## [1.0.0] - 18 October 2026

- Search any SearXNG instance with autosuggestions from its `/autocompleter` endpoint
- Instance URL, category, language and safe-search preferences
- Image, video and map search shortcuts: Shift-Cmd-I, Shift-Cmd-Y, Shift-Cmd-M
- Search selected text, with optional clipboard fallback
- Search history stored locally per instance
